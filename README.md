# Daniel Trading Bot — MVP

## Pornire locală
```bash
pip install -r requirements.txt
streamlit run app.py
```

Aplicația este paper trading. Nu folosește bani reali și nu se conectează la exchange.

## Publicare
Poate fi publicată ulterior pe Streamlit Community Cloud sau alt serviciu de hosting. Înainte de trading real trebuie adăugate autentificare, baze de date, protecții, audit, testare și verificarea obligațiilor legale.
